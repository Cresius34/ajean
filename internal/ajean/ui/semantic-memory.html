Clé d’accès à cette interface, si tu en as défini une

1. Réglages mémoire généraux

Au premier usage, lance Installer-Modele.cmd dans le dossier extrait (310 Mo). Le moteur CPU compatible est fourni dans le paquet.

Le GGUF traite le texte. Les autres modalités nécessitent Installer-Multimodal.cmd puis le moteur complet. Un preset peut remplacer ces valeurs générales.

Vecteurs en RAM · dimensions réduites = index plus léger, sans réduire les poids du modèle. Le placement concerne l’encodeur mémoire, indépendamment du moteur de conversation.

2. Notes du projet d’essai

Place des copies de tes notes .md dans le dossier affiché ci-dessous. Tu peux aussi lancer Copier-Memoire.cmd, qui lit ta mémoire actuelle et copie les fichiers manquants dans ce dossier d’essai.

Le projet actif dans le chat détermine le dossier interrogé. Un changement externe est détecté à la recherche suivante ; l’index est actualisé en arrière-plan et cette première recherche utilise les mots.

3. Réutiliser Swift pour le chat

Démarre ton Ajean habituel, puis vérifie la connexion. Cette copie appelle son API et ne pilote pas son service.
